### sbt project compiled with Scala 3
### Usage



## Description

This is a simple implementation of the card game Werwolf, writen in scala

Werewolf is a social deduction game where players secretly take on roles in a village—some are harmless villagers, others are bloodthirsty werewolves. Each “night,” the werewolves secretly pick someone to eliminate. Each “day,” everyone argues, accuses, and votes on who they think the werewolves are. The goal: villagers try to find and eliminate all werewolves before the werewolves outnumber them. It’s basically lying, guessing, and pretending to trust your friends until someone snaps.
